# Plan 06 — Communications

Status: active, September 30, 2026.

## Objective

Review NSPRA audit, communications plan, newsletter/website/ambassador implementation and end-of-year metrics. Separate published outputs and status labels from demonstrated reach, engagement, accessibility and partnership outcomes.

## Bounded work

1. Recover audit recommendations, dated plan and implementation artifacts; distinguish author recommendations from district execution.
2. Review an existing end-of-year metrics/department report and website/ambassador traces. Preserve definitions, periods, denominator limits and source conflicts.
3. Classify design, implementation, attainment and recurrence, then close research with explicit gaps.

## Stopping rule

Targeted Board/department/audit/report review is sufficient. No new website analytics pipeline, social-media census, indefinite search for internal metrics or waiting for 2027 deadlines. Missing public engagement data are not zero engagement. Completed newsletter/plan outputs do not demonstrate increased reach. Reopen only for a concrete authoritative implementation or comparable reach/engagement measure.
