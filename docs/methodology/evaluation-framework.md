# Evaluation Framework

For each strategic objective ask:

1. Was the problem correctly identified?
2. Were chosen tasks reasonably capable of addressing it?
3. Were tasks implemented?
4. Was implementation fidelity demonstrated?
5. Did relevant outcomes improve?
6. Did Riverview improve relative to Washington or an appropriate comparison where applicable?
7. Did focal-group gaps narrow while focal-group outcomes improved?
8. Did the problem recur, evolve, resolve, or become institutionalized?

## Task design
Strong / Appropriate but incomplete / Weak or activity-oriented / Poorly aligned / Insufficient evidence.

## Implementation
Not started / Partially implemented / Implemented / Cannot determine.

## Goal attainment
Met / Partially met / Not met / Cannot determine.

## Recurrence
Sustained responsibility / Evolving challenge / Persistent unresolved problem / Recurrent implementation failure / Measurement failure / Resolved or institutionalized.

Task completion is not outcome attainment.
