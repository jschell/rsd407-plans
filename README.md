# RSD407 Strategic Plan Evaluation

Evidence-driven evaluation of Riverview School District No. 407 strategic plans, implementation, outcomes, and recurring challenges.

## Principles

- **Reproducible:** every pulled dataset records source, retrieval method/date, identifiers, and transformations.
- **Testable assertions:** evaluative claims carry evidence IDs that resolve to source records or reproducible calculations.
- **Separate evidence from judgment:** observations, derived measures, and evaluation conclusions are stored distinctly.
- **No silent substitution:** secondary sources never masquerade as primary/authoritative data.
- **Preserve uncertainty:** suppression, missing data, incompatible measures, and unresolved conflicts remain explicit.

## Repository map

- `docs/methodology/` — evaluation and reproducibility rules
- `docs/evidence/` — evidence ledgers and provenance
- `docs/evaluations/` — domain evaluations
- `docs/strategic-plans/` — plan reconstruction by era
- `docs/plans/active|queue|complete/` — research work plans
- `data/manifests/` — machine-readable dataset/source manifests
- `scripts/` — reproducible collection/transformation scripts
