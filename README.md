## Principles

- **Reproducible:** every pulled dataset records source, retrieval method/date, identifiers, and transformations.
- **Testable assertions:** evaluative claims carry evidence IDs that resolve to source records or reproducible calculations.
- **Separate evidence from judgment:** observations, derived measures, and evaluation conclusions are stored distinctly.
- **No silent substitution:** secondary sources never masquerade as primary/authoritative data.
- **Preserve uncertainty:** suppression, missing data, incompatible measures, and unresolved conflicts remain explicit.
